About The Project

Intelligent Greenhouse Monitoring System Based on IoT and Machine Learning

EEE Department · University of Peradeniya · 2025–2026

This Final Year Project introduces an automated IoT-based mushroom cultivation system designed to modernize traditional mushroom farming in Sri Lanka — transitioning farmers from experience-based to precision-based agriculture.

We visited Uhumeeya Global Green Agro Pvt Ltd in Week 2 to gain hands-on practical knowledge about oyster mushroom cultivation, environmental requirements, and the real challenges faced by Sri Lankan farmers.

Hybrid VLC + LoRa Communication

VLC downlink for actuator commands; LoRa uplink for long-range sensor data — resistant to RF interference from greenhouse motors

Machine Learning Disease Detection

CNN-based image analysis with 940nm NoIR camera detects Trichoderma, Bacterial Blotch and Cobweb Mold before visible symptoms appear

Server-Client IoT Architecture

Central server runs Fuzzy Logic and ML — ESP32 nodes act as lightweight sensors, one dashboard controls multiple sheds

Core Technologies

What Powers Our System

VLC Downlink

Uses existing LED lighting to broadcast commands to actuators. Immune to RF interference from fans and water pumps. High-bandwidth, low-latency path for controlling the greenhouse environment.

Blue 450nmRed 660nmFar-Red 730nmLow Latency
LoRa Uplink

Long Range radio sends sensor data from shed nodes to the central gateway. Covers several kilometres, penetrates thick walls, and runs for long periods on battery — ideal for rural Sri Lankan farms.

Long RangeLow PowerWall PenetrationMulti-shed
IoT Sensors

DHT22 sensors for temperature and humidity, CO2 sensors for ventilation control. All nodes report to the central server which computes the optimal growth recipe and sends back commands via VLC.

DHT22CO2 SensorESP32Real-time
NoIR Imaging (940nm)

ESP32-CAM with 940nm infrared LEDs captures high-contrast images in biological darkness. Detects diseases before they are visible to the human eye using Near-Infrared Reflectance changes.

940nm IRESP32-CAMPre-visualHigh Contrast
CNN Disease Detection

Convolutional Neural Networks identify Trichoderma, Bacterial Blotch, and Cobweb Mold. TinyML runs on-device for basic detection; complex cases go to cloud GPU for analysis of 50+ disease types.

CNNTinyMLCloud GPU50+ Diseases
Server-Client Architecture

Central server runs Fuzzy Logic and ML algorithms, overcoming ESP32 RAM limits. Archives historical growth data, predicts harvest times, and manages multiple sheds from one dashboard.

Fuzzy LogicML PredictionData ArchiveMobile App
System Design

Control & Execution Workflow

The seamless data loop connecting long-distance LoRa communication with localised VLC-based execution

1. Sense

DHT22 + CO2 sensors collect environment data at the node

2. Transmit

Node sends data via LoRa to central gateway

3. Analyse

Server compares data to optimal growth recipe, calculates commands

4. VLC Command

Blue LED flashes a high-speed code to the actuator receiver

5. Actuate

Mist maker, fan or water pump activates for the calculated duration

Disease Detection Branch

ESP32-CAM captures NoIR images → Wi-Fi to server → CNN identifies Trichoderma, Bacterial Blotch, Cobweb Mold → Alert + proactive ventilation increase

Farmer Mobile Dashboard

Live temperature, humidity, CO2, and disease alerts. One farmer can monitor multiple sheds simultaneously — reducing 3–4 hours of daily manual work to just a few minutes
