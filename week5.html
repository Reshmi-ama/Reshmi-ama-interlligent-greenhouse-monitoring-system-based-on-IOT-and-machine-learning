// Context

Why Machine Learning?

Following the wavelength research in Week 4, we identified that the relationship between LED light conditions and mushroom yield is complex and multi-variable — it involves wavelength, photoperiod duration, environmental temperature, humidity, and growth stage simultaneously. A rule-based or threshold control system would be too rigid to optimise across all these variables.

This week we began studying machine learning fundamentals as the basis for building a predictive model that can learn from cultivation data — including sensor readings and yield measurements — and assist in recommending optimal LED configurations. The published work by Moysiadis et al. (2023) on ML-based mushroom growth monitoring directly validated this direction for our FYP.

// ML Fundamentals

Core Concepts Studied

The foundational concepts covered this week, primarily through the 3Blue1Brown neural network series, are outlined below.

🧠
Neural Networks

Layered structures of interconnected nodes (neurons) that learn patterns in data. Each layer transforms its input, progressively building more abstract representations toward a final output.

↩
Backpropagation

The algorithm by which a neural network learns — it calculates how much each weight contributed to the output error, then adjusts weights in the direction that reduces that error.

〜
Activation Functions

Non-linear functions (ReLU, Sigmoid, Tanh) applied at each neuron, enabling the network to learn non-linear relationships — essential for modelling the complex interactions between light and growth.

⬇
Gradient Descent

The optimisation method used to minimise the loss function. Weights are iteratively nudged in the direction of steepest descent on the loss surface to improve model accuracy over training epochs.

📉
Loss Functions

Metrics that quantify how far the model's predictions are from the true values. Mean Squared Error (MSE) is particularly relevant for regression tasks like predicting mushroom yield from sensor data.

⚙
Training & Validation

The process of splitting data into training and validation sets, fitting the model on training data, then evaluating generalisation on unseen validation data to detect overfitting.

// Application

How ML Connects to the Cultivation System

Machine learning is not just an academic study for this week — it maps directly onto the three functional stages of our automated system.

Inputs
Sensor Data Collection

Temperature, humidity, CO₂, and growth stage data collected by sensors inside the mushroom house are fed as features into the model.

Processing
Wavelength Effect Prediction

The trained neural network predicts expected yield and quality for different LED wavelength and photoperiod combinations given the current environmental conditions.

Outputs
LED Control Recommendation

The model's output drives the downlink VLC signal — adjusting LED colour, intensity, and duty cycle automatically to optimise cultivation outcomes in real time.

// Key Paper Review

Moysiadis et al. (2023) — Findings

📄

Agriculture · MDPI · 2023

Monitoring Mushroom Growth with Machine Learning

Moysiadis, V., Kokkonis, G., Bibi, S., et al.

Cited: 59

Approach

Used ML models to monitor and predict mushroom growth parameters from environmental sensor data, demonstrating feasibility of data-driven cultivation management.

Sensors Used

Temperature, humidity, CO₂ concentration, and image-based growth measurements — closely aligned with our planned sensor configuration.

Relevance to FYP

Validates our approach of combining sensor data with ML for automated cultivation decisions. Provides a model architecture reference for our wavelength-optimisation component.

Key Takeaway

ML-based monitoring outperformed static threshold rules in maintaining optimal growth conditions, supporting the use of adaptive ML over fixed rules in our system.

DOI: 10.3390/agriculture13010223

ML Study Progress

What is a neural network?

Layers, weights, biases, and how data flows forward through the network to produce a prediction (forward pass).

Gradient descent and learning

How the network minimises its loss by computing gradients with respect to each weight and nudging them in the downhill direction.

3

Backpropagation — the math

Chain rule derivation of how error signals propagate backwards through layers to update weights. Studied via 3Blue1Brown Chapter 3.

Backpropagation — calculus notation

Formal notation used in academic literature; understanding partial derivatives of the loss with respect to weights and activations.
