ML & VLC
Integration in Agriculture

Investigating how machine learning techniques — regression models, deep neural networks, and convolutional neural networks — can be combined with VLC to build a smarter, self-adapting mushroom cultivation system.

// Overview

Research Focus This Week

This week's research shifted focus toward the intelligence layer of the system — specifically, how machine learning can be integrated with Visible Light Communication to overcome real-world agricultural challenges. A greenhouse environment introduces problems that a static VLC system cannot handle alone: fog and humidity attenuate the light signal, multipath reflections off walls and substrate bags distort transmitted data, and fixed light timers cannot respond to the biological state of the growing mushrooms.

Three ML-based approaches were identified from literature, each targeting a distinct failure point in the VLC–agriculture pipeline. These techniques will inform the software architecture of our system in later weeks.

// ML Techniques

Three Integration Approaches

1
Predictive Signal Boosting Regression ML

⚠ The Problem

Fog and humidity in the mushroom shed block VLC light signals, causing signal drops that interrupt data transmission between the controller and sensors.

✓ The Solution

ML regression models learn how fog conditions affect light intensity. The system can then predict signal drops before they happen and automatically boost LED brightness to push through the fog before data is lost.

2
Distortion Correction Deep Neural Networks

⚠ The Problem

Light bouncing off walls and substrate bags (multipath reflection) distorts the digital signal at the receiver, causing bit errors and corrupted sensor readings.

✓ The Solution

A Deep Neural Network learns the room's unique reflection pattern, acting as a highly advanced equalizer to clean up distorted light waves and perfectly reconstruct the original transmitted data.

3
Vision-Driven Dynamic Lighting CNNs

⚠ The Problem

Static light timers aren't optimised for real-time biological needs — mushrooms at different growth stages require different light spectrums, but fixed schedules cannot respond to what's actually happening.

✓ The Solution

Computer vision (CNN) monitors plant growth in real-time. When the AI detects a mushroom is ready for the next growth stage, it uses VLC to instantly adjust the LED light spectrum (e.g., triggering blue lights at 475 nm) to save energy and maximise yields.

💡

Key insight: Each technique targets a different layer — Regression ML handles the physical channel, Deep Neural Networks handle the signal processing layer, and CNNs handle the application layer. Together they form a complete intelligent VLC pipeline for smart agriculture.
