Learning the fundamentals of machine learning, understanding why growth-stage identification matters, and building an image dataset for YOLOv8-based detection.

Week 13 Machine Learning Data Collection

Learning Machine Learning

This week's focus was on learning the fundamentals of machine learning as the next building block for the system's automated growth-stage monitoring. A key takeaway was understanding why it matters to correctly identify the pinning stage and the fruiting stage of the mushroom growth cycle — these two stages mark the transition points where environmental control decisions (light, humidity, ventilation) have the biggest impact on yield.

Pinning Stage

The stage where tiny mushroom primordia ("pins") first appear — an important trigger point for adjusting environmental conditions.

Fruiting Stage

The stage where mushrooms mature and grow to harvestable size — accurate detection here supports harvest timing.

Dataset Creation

Work began on building an image dataset for training the stage-detection model. Photos are being captured using the camera setup already installed in the mushroom house, capturing the natural progression of growth stages under real cultivation conditions.

Data Source

Images are captured directly from the in-house camera setup installed in the mushroom house, providing real, on-site growth images rather than external reference images.

Planned Approach — YOLOv8

The plan going forward is to use YOLOv8 for stage detection. As an object detection model, YOLOv8 is intended to be trained on the collected dataset to detect and localize the pinning and fruiting stages directly from captured images, which can later feed into the system's automated monitoring pipeline.
